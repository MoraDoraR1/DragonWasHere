## 4. 집 PC에서 Claude Code가 할 일

1. **규칙 확인**: `CLAUDE.md` → `README.md`, `작업내용.md`, `메모.md`를 읽고 특이사항을 보고한다(README 규칙 1번). 답변은 한국어로만 한다.
2. **경로 확인**
   - 바탕화면 원본 경로가 회사 PC(`C:\Users\user\Desktop\...`)와 다를 수 있다. `Desktop\DragonWasHere_기획서및리소스\임시unity제작.md`를 찾아 그 경로로 동기화한다. 없으면 사용자에게 알린다.
   - 기억(`memory`) 폴더가 비어 있으면 USB의 `claude_memory`를 복사했는지 사용자에게 확인한다. 핵심 내용은 아래 5번에도 적어 두었다.
3. **Library 재생성 + 데이터·씬 빌드** (Unity 에디터가 닫혀 있을 때. 처음엔 오래 걸림)
   ```bash
   "C:/Program Files/Unity/Hub/Editor/6000.3.19f1/Editor/Unity.exe" -batchmode -nographics -quit -projectPath . -executeMethod DWH.Editor.SceneBuilder.BuildAll -logFile Logs/build.log
   ```
   - 로그에 `[DWH] 게임 씬 생성`이 나오면 정상. Unity 설치 경로가 다르면 맞게 바꾼다.
4. **테스트로 상태 확인**
   ```bash
   "C:/Program Files/Unity/Hub/Editor/6000.3.19f1/Editor/Unity.exe" -batchmode -nographics -projectPath . -runTests -testPlatform EditMode -testResults Logs/edit.xml -logFile Logs/edit.log
   ```
   ```bash
   "C:/Program Files/Unity/Hub/Editor/6000.3.19f1/Editor/Unity.exe" -batchmode -projectPath . -runTests -testPlatform PlayMode -testResults Logs/play.xml -logFile Logs/play.log
   ```
   - PlayMode는 캡처(`Logs/Screens`)를 위해 `-nographics` 없이 돌린다.
   - 회사 PC 마지막 결과(아래 6번)와 같으면 정상적으로 옮겨진 것이다.
5. **지켜야 할 규칙 (기억 요약)**
   - 커밋은 사용자가 요청할 때만. 형식 `[MOD/ADD/DEL]YYYYMMDD_내용_Claude`, 섞이면 우선도 높은 태그(MOD > ADD > DEL) 하나만 제목에, 나머지는 본문에.
   - `Docs/임시unity제작.md`를 먼저 고치고 바탕화면 원본에 똑같이 반영.
   - 작업이 끝날 때마다 `작업내용.md`(최신이 위)와 `메모.md`(체크리스트) 갱신.
   - 문제는 사용자에게 수동 단계를 넘기지 말고 끝까지 직접 해결. 단, Unity 에디터가 열려 있으면 강제 종료하지 말고 사용자에게 닫아 달라고 한다.
   - 파일 다운로드는 파일명·출처·크기를 말하고 허락을 받은 뒤에만.
